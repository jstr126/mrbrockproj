Connection notes

Open the Pi's LAN address from any computer on the same Ethernet network. Viewers need only a browser; no ChatGPT account, installation or SSH tunnel is required. The camera is connected to the Pi. This page has no external assets or cloud inference dependency. SSH is used for deployment and administration. Pausing the view does not stop camera capture on the Pi.

Processing time includes board detection, rectification, the model and geometric measurement. Result age is measured on the Pi; network transit, camera exposure and internal camera buffering are not included. Model accuracy does not establish jam-free operation; a physical bypass, blockage sensor and feeder stop are still required.
